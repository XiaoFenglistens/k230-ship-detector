## 二、准备工作（3 分钟，一次性）

1. **把场景图投到你的 2560×1440 屏上**，缩放到"铺满整个屏幕"（图片本身就是 2560×1440，
   用 Windows 照片查看器全屏 / F11 即可，不要让它自动留边缩放）。
   - 亮度和对比度调到平时看图的水平，**关掉夜间模式/护眼模式**。
2. 房间光照：**开主灯**（曝光时间短 → 不容易拍虚）。
3. 板子接不接电脑都行；接了方便我传脚本，不接也能跑（用 CanMV IDE 传一次即可）。

## 三、板子这边（我做好了，你只管跑）

脚本：`D:\rs-yolo\tools\cap_burst.py`


## 四、拍摄流程（每组一遍，共 6 遍）

1. **摆好位置**——板子对着屏幕。建议把板子**靠在书堆上或平放桌上抬高**，不要一直举着。
   近距约 20–25cm（画面里屏幕占大半），远距约 40–45cm（画面里能看到屏幕四条边）。
2. **短按一下 USR**（按完立刻把手拿开）。
3. 屏幕出现 `倒计时 3 / 2 / 1 手请拿开`，然后绿灯亮，自动连拍 20 张（约 20 秒）。
   - **这 20 秒里不要碰板子**，也不要走动挡光。
4. 屏幕显示 `第 N 组 完成`。
5. **换下一个位置**（对照上面的表），再短按一次 → 自动进第 N+1 组。
6. 6 组拍完，**长按 USR 3 秒退出**。

> 小提示：如果某一组拍完发现忘了调位置，直接再按一次会变成下一组号，不用管——
> 我可以按组号筛选，多余的丢掉就行。

## 五、拍完怎么交给我

照片在 `/sdcard/photo/cap/`，文件名 `g01_001.jpg` … `g06_020.jpg`。

你说一声"拍完了"，我负责：

2. 跑筛片（三档：A 清晰 / B 可用 / X 剔除）
3. 跑标注迁移，抽 6 张可视化给你过目
4. 用现有模型在这个集上跑一遍，出基线数字

## 六、筛片规则（已写好并自测通过）

`D:\rs-yolo\tools\cap_filter.py`

| 档 | 条件 | 用途 |
|---|---|---|
| **A 清晰** | 清晰度 ≥ 组内 p75×0.45 且内点 ≥ 300 | 干净基线 |
| **B 可用** | 清晰度 ≥ 40、内点 ≥ 150、重投影 ≤ 3.5px、可见率 ≥ 40% | 真实条件 |
| **X 剔除** | 以上任一不满足 | 标注不可信 |

自测（8 张合成退化图）结果：清晰 4 张全 A、轻糊 2 张 B、重糊 2 张 X —— 分档符合预期，
标注投影目视完全贴合船只。

## 七、为什么这样拍（给论文用的一句话）

> "为评估真实低分辨率成像条件，我们在 2560×1440 显示屏上投放航拍影像，以 1280×720 级
> 边缘视觉传感器在 20–45cm 距离采集 6 组共 120 帧，并通过 SIFT 单应性将原图标注迁移至
> 实拍帧；按清晰度与配准可靠性分档，得到 A/B 两档评测子集。"

——这句话把"拍屏幕"这种土办法，变成了**可复现、有质量分级的采集协议**。
